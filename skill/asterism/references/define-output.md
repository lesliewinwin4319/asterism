# Define output contract

Save each result as `asterism/define/<slug>-vN.md`, incrementing `N` without overwriting an existing file.

The Markdown document must contain:

```markdown
# <Goal title>

## Original Request

## Problem Statement

## Desired Outcome

## Success Criteria

## In Scope

## Out of Scope

## Constraints

## Confirmed Facts

## Assumptions

## Open Questions

## Relevant Reference and Context

## Decision Log

## Skills and Work Units Used

## Readiness
Draft | Needs clarification | Ready for Solutions
```

Use source item IDs or stable artifact/link identifiers in `Relevant Reference and Context`. Record selected Skill names and user-visible work-unit labels, not private reasoning or internal Agent IDs.

Set `Ready for Solutions` only when the problem, outcome, success criteria, scope, and constraints are sufficiently clear; important assumptions and open questions must not be disguised as facts.
